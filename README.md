# Qt-Framework-Learning

A collection of C++ implementations exploring the Qt Framework. Covers core concepts: Object Trees, Event Handling, Custom Widgets, and Resource Management. Based on Udemy's Qt Widgets curriculum.

The goal of this path is to expand my **C++** expertise by mastering cross-platform desktop GUI development.

---

## Key Concepts & Technical Skills

Through these implementations, I have gained hands-on experience with the core pillars of the Qt Framework:



**Core Architecture:** Managing memory via the Qt Object Tree, understanding the Meta-Object System, and utilizing the `Q_OBJECT` macro.

**Signals & Slots:** Implementing decoupled communication between the UI and application logic.

**Layout Management:** Building responsive interfaces using `QVBoxLayout`, `QHBoxLayout`, and `QGridLayout`.

**Standard Widgets:** Working with essential components such as `QMainWindow`, `QDialog`, `QPushButton`, and `QListWidget`.

**Event Handling:** Overriding mouse and keyboard events to create interactive user experiences.

**Build Systems:** Managing projects using **CMake**.
